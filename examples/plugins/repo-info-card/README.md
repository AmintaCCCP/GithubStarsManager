# Repo Info Card example (V1.4 弹窗动作)

通过宿主当前配置的 AI Provider,把单个仓库的元信息与 README 整理成一张可分享的
单文件 HTML 信息卡,并提供预览、复制代码、复制/保存 PNG 截图。

## 安装与入口

1. **设置 → 插件 → 安装本地插件**,选择本目录,确认权限后启用。
2. 在任意仓库卡片的 `…` 菜单 → **插件操作** → **生成仓库信息卡**。宿主会在弹窗中
   打开本插件的页面(Manifest 中 `repositoryActions[].opensPage` 指向的页面),并随
   `plugin-page:init` 一次性下发所点击仓库的元数据、README 正文、界面语言与主题。
3. 本页面也可以从 **设置 → 插件 → 打开页面** 进入;该入口没有仓库上下文,页面会
   提供一个搜索框,通过 `repositories.search` / `repositories.get` 选择仓库(此时
   没有 README,只用元信息)。

## 页面布局与控件风格

页面为左右布局:左侧是配置区(仓库信息、风格/画幅/卡片语言、生成按钮与状态栏),
右侧是预览区(缩放条、画布与导出动作)。窗口过窄时自动退化为上下堆叠。

控件风格与主程序保持一致:页面自带一份与 `src/index.css` 相同的 Linear 设计令牌
(HSL 变量、圆角、边框、hover/focus 态),弹窗入口会随 `plugin-page:init` 下发的
`theme` 切换深浅色;面板入口没有主题上下文时退回系统偏好。

## 配置项(卡片选项卡)

三个配置项都是卡片选项卡,交互与应用外观设置里切换主题预设一致:点击选中,
选中卡片有 primary 描边 + 光环 + 右上角对勾角标,方向键可在卡片间移动并同步选中。

- **风格**:TE 纸面 / 暗色仪器 / 极简黑白,卡片上用调色板本身画了迷你示意。
  风格只影响插件自带的 CSS 调色板,切换风格不需要重新调用 AI。
- **画幅**:预设卡片 1:1(1200×1200)、5:2(1500×600)、3:4(1200×1600),卡片上按
  真实长宽比画出画布轮廓;另有横跨整行的 **自定义** 卡片,选中后出现长宽输入框
  (400 – 3000 px,四舍五入取整),可自由指定画幅尺寸。导出 PNG 始终为 @2x。
- **卡片语言**:跟随界面,或 i18n 支持的任一语言(中文 / English / 日本語 /
  Español / Português (Brasil) / Русский / 繁體中文 / Français / Deutsch /
  한국어),与 `src/i18n/languages.ts` 的 APP_LANGUAGES 一致。
- **附加说明**(选填):用户对信息卡的附加要求(≤600 字符,如「重点介绍插件
  系统」「标题更收敛」),生成时会以 `USER REQUIREMENTS` 段落注入用户提示词;
  要求只能调整侧重与措辞,不允许越过输出规则或引入仓库信息之外的事实。
  修改后需重新生成才会生效。

## 预览:标签切换、缩放与拖拽

预览区顶部是「预览 / 代码」分段标签:

- **预览**:渲染后的信息卡,即下方描述的缩放与拖拽;
- **代码**:卡片的 HTML 片段(AI 输出经净化后的内容),带语法高亮(插件自带的
  轻量分词器,不依赖外部库),可直接编辑;切回「预览」时自动净化并应用修改,
  预览随之更新。若修改后的代码缺少 `id="card"` 根元素,会停留在代码页并在
  状态栏提示。
- 「复制 HTML 代码」按钮导出的始终是完整单文件 HTML(包含已应用的修改)。

预览区上方是缩放条:

- `−` / `+` 按 1.25 倍逐级缩放,比例限制在「适应窗口」的 0.2× ~ 6×;
- 百分比按钮与 **适应窗口** 回到自适应比例;
- **实际大小** 切到 100%(卡片按导出像素显示);
- 在预览区按住 `Ctrl` / `⌘` 滚动滚轮也可缩放。

画布放大到超出预览区后,按住鼠标拖拽即可平移画布(光标变为抓手);触摸设备
保留原生滚动手势。预览只改变显示比例,导出的 PNG 始终按画幅的 @2x 尺寸生成。

## 工作方式

- 插件持有版式 CSS 与系统提示词(≤2000 字符,受 `ai.generate` 参数上限约束);
  AI 只输出卡片的 body 标记。插件会对 AI 输出做净化(移除 script/style/图片、
  `on*` 事件属性与 `javascript:` URL),并校验 `id="card"` 根元素。
- **画幅与版式解耦**:`data-canvas` 只承载尺寸(`--w`/`--h`/字号/留白),
  `data-layout`(square / banner / portrait)决定结构规则。自定义画幅按长宽比
  自动落入对应版式,字号与留白按短边相对 1:1 画幅缩放。
- **提示词携带 README 全文**:宿主 `ai.generate` 正文上限放宽到 160000 字符后,
  README 原样(不清洗、不改写、不摘要)以 `README (full text):` 放进提示词;
  只有超过该上限的极少数 README 才会被截断,此时标注
  `README (full text, truncated at the prompt limit):`,状态栏也会提示已截断。
  提示词同时要求 AI 以 README 为准,一行描述与 topics 只用来补缺。
- 已生成的卡片固定在生成时的画幅上:切换画幅(或修改自定义长宽)后截图导出会
  禁用,状态栏提示重新生成;风格切换始终即时换肤,不需要重新生成。
- 预览渲染在 shadow DOM 中,与页面自身样式隔离。**卡片样式通过
  Constructable Stylesheet(`adoptedStyleSheets`)注入**,因为页面 CSP 是
  `style-src plugin-page://<id>`(不含 `unsafe-inline`),动态插入 `<style>`
  元素会被拦截、卡片会退化成浏览器默认样式;同时调色板变量挂在 `#card` 上,
  而不是 `:root`(后者在 shadow tree 中匹配不到任何元素)。
- 截图通过 SVG `foreignObject` + `<canvas>` 光栅化为 @2x PNG(纯文本卡片,不依赖
  外部资源),随后:
  - `clipboard.writeImage`(权限 `clipboard:write`)复制到剪贴板;
  - `downloads.saveFile`(权限 `downloads:create`)弹出宿主原生保存对话框。
- 复制代码通过 `clipboard.write` 输出完整的单文件 HTML(可直接在浏览器打开,
  `<html lang>` 跟随所选卡片语言)。

本插件无 `worker.js`:它是「页面 + 弹窗动作」的纯页面型插件,不启动 Node Worker。
