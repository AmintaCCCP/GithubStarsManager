# Repo Custom Fields example (V1.6 非全屏弹窗动作)

给每个仓库附加一组自定义字段：单行文本、多行文本（Markdown 或代码高亮渲染）
与可点击的 URL 链接。查看与编辑都在一个**非全屏的小弹窗**里完成，交互参考
1Password 的登录项「预览 ⇄ 编辑」两态，并针对桌面（鼠标 + 键盘）做了适配。

## 安装与入口

1. **设置 → 插件 → 安装本地插件**，选择本目录，确认权限后启用。
   需要的权限：`repositories:read`（读取仓库身份）、`storage`（字段数据）、
   `clipboard:write`（预览里的复制按钮）、`external:open`（点击链接时交给系统浏览器）。
2. 在任意仓库卡片的 `…` 菜单 → **插件操作** → **仓库自定义信息**。宿主会打开
   本插件页面；因为 Manifest 中动作声明了 `"display": "popup"`，弹窗是
   非全屏的紧凑形态（详见 docs/plugins/v1-development.md 的 V1.6 一节）。
3. 本页面也可以从 **设置 → 插件 → 打开页面** 进入；该入口没有仓库上下文，
   页面会提供搜索框，通过 `repositories.search` 选择仓库。

## 交互

- **预览**：点插件动作进入预览视图，字段按保存顺序展示。链接字段显示为可
  点击的链接（带外链图标），点击后经 `shell.openExternal` 桥用系统浏览器
  打开；说明字段按添加时选择的格式渲染 Markdown 或代码高亮。
  每个字段右上角有复制按钮（`clipboard.write` 桥），复制的是保存的原始值——
  链接复制 URL、说明复制 Markdown/代码源码、文本复制文本本身，复制成功后
  图标短暂变为对勾。
  预览里的长内容一律软换行：文本、Markdown 段落、代码块都按宽度折行，不会
  因长行出现横向滚动。
- **编辑**：点右上角铅笔图标进入编辑视图。每行有拖拽把手（按住把手才能拖动，
  不干扰输入框的选择；把手也可聚焦，Alt+↑/↓ 键盘移动行）、删除按钮、名称输入框
  与值编辑器；说明字段有 Markdown/代码 格式切换。底部三个「＋」按钮分别添加
  单行文本、多行文本与链接。
- **保存**：点右上角对勾图标保存并回到预览；名称必填（链接字段可留空，此时直接
  显示 URL），链接必须是保留地址之外的 http(s) 地址（按字面主机名拒绝回环、IPv6
  链路本地/唯一本地地址；不解析 DNS，`192.168.x.x` 这类普通内网地址也可保存），
  整份文档不超过
  本地 storage 的 64 KiB 单值上限，未通过校验的行会高亮并给出原因。Esc 或叉号
  图标放弃修改。
- 读取完成前编辑入口不可用；读取失败时工具条给出重试按钮，避免用空草稿覆盖已存
  字段。保存请求在途时编辑与取消均被锁住，防止旧请求用旧草稿覆盖新改动。
- 数据以 `fields:<repository id>` 为键存进插件 storage（本地文件，上限
  64 KiB/值、1 MiB/插件），与宿主账号无关。

## 实现说明

- 无 `worker.js`：纯页面型插件（opensPage 动作），不启动 Node Worker。
- 页面 CSP 没有外部资源：Markdown 渲染与代码高亮由自带的 `ui/model.js`
  轻量实现（纯函数、无依赖），该模块同时被 `electron/plugins/repoCustomFieldsModel.test.js`
  以 node --test 直接测试。
- 所有动态文本先转义再拼 HTML；Markdown 链接只生成 `data-url`，由页面统一
  经外链桥打开，绝不产生可导航的 `<a href>`（沙箱 iframe 的导航会被宿主拦截）。
